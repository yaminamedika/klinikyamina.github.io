💾 Backup & Export — Data Klinik Yamina

☁️ Sinkron Otomatis (Cloud)
Config Cloud sudah terpasang untuk project rm-apotek-9d889. Pastikan di Firebase sudah: 1) Firestore Database dibuat, 2) Authentication → Anonymous di-Enable, 3) Rules sudah Publish. Setelah deploy ke Vercel, status di atas jadi ● Cloud: Tersambung dan input kasir langsung muncul di HP.
Backup itu wajib. Export JSON untuk backup lengkap (bisa restore 100%), Excel untuk dibuka di Excel / dibagikan, CSV untuk dibuka di Excel / Google Sheets. Simpan file backup di flashdisk / Google Drive tiap minggu.

💾 Auto-save ke localStorage — Aktif

Setiap klik Simpan / Checkout langsung tersimpan ke localStorage browser ini (kunci yamina_terpadu_v2). Ketikan di form yang belum diklik Simpan dan keranjang Kasir juga tersimpan otomatis sebagai draft tiap ketikan, tiap 30 detik, dan saat tab ditutup / disembunyikan. Buka lagi file ini di browser & laptop yang sama, datanya kembali.

Penting: Auto-save itu lokal, bukan cloud. Beda browser / beda laptop = data beda. Kalau hapus riwayat browser, localStorage bisa ikut terhapus. Jadi tetap Export JSON tiap minggu sebagai backup.
